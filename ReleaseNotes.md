## MediaLens v1.2.10

### Summary

This release makes MediaLens feel more responsive in everyday review and metadata workflows. Tag filtering, bulk editing, duplicate review, and comparison panel resizing now do less unnecessary work and show visible results sooner.

### Highlights

- Filter galleries by tag with quicker visible updates and less blocking tag-list refresh work.
- Review duplicates and similar files without the gallery getting stuck behind off-screen loading steps.
- Save per-file bulk tags and descriptions directly, with more stable row layouts as the sidebar resizes.

### Notes

- This release focuses on responsiveness and UI reliability rather than installer or runtime packaging changes.
- Additional performance timing is now available in app logs for future tuning passes.
